What is real in v5, and what is not

PasswordsStored only as salted scrypt hashes (N=2^17, r=8, p=1). Not plain SHA-256.
Roles and actionsChecked on the server for every protected route, not only in this page. Only the admin creates accounts or changes roles.
One deviceThe browser keeps a non-extractable signing key. Login needs the password and a fresh signature from that key. It binds to this browser profile, not to physical hardware. Clearing site data loses it.

Not coveredNo HTTPS on localhost, no face or biometric login, in-memory sessions, no hardware attestation, not production security.
